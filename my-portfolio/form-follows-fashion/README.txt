# Form Follows Fashion landing page

## Files
- `index.html` — page structure and content
- `style.css` — responsive styling and theme colors
- `script.js` — category filters, search, mobile menu, cart, newsletter demo

## Run locally
Open `index.html` in a browser. An internet connection is needed for Google Fonts and the Unsplash photos.

## Customize before publishing
1. Replace the sample product names, prices and photos with the store's real stock.
2. In `script.js`, set `whatsappNumber` to the store's verified WhatsApp number using digits only, including Kenya country code `254`.
3. Connect newsletter signup to an email marketing service.
4. Connect checkout/payment and inventory to a real ecommerce backend. The current cart is front-end demo functionality and does not process payments or save orders.
5. Confirm the exact shop address and delivery policy before publishing.

Colors: `#e9d8c9` and `#b77b60`.
